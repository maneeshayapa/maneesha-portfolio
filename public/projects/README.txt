PROJECT SCREENSHOTS
===================
Drop your real screenshots in this folder, e.g.

  ledgerly.png
  ngems.png
  churn-prediction.png
  sales-prediction.png
  clinic-book.png
  ridebuddy.png
  researchmate.png

Then open src/data/projects.js and set the `screenshot` field of the matching
project, for example:

  screenshot: '/projects/ledgerly.png',

Until a screenshot is set, the site shows a clearly labelled placeholder.
Recommended size: 1600 x 900 px (16:9), PNG / JPG / WebP.
